# Block World

A small blocky voxel game for Android, written in Rust with the Bevy engine.

## Controls

- **Left side of screen:** drag to walk
- **Right side of screen:** drag to look around
- **Quick tap:** place a stone block where you're aiming
- **Press and hold:** break the block you're aiming at

## Getting the APK

1. Push this project to your GitHub repo. The build runs on every push.
2. Open the repo's **Actions** tab and click the latest run.
3. At the bottom of the page, download **blockworld-apk** and unzip it.
4. Copy the `.apk` to your phone and open it. You may need to allow installs from that app.

The first build is slow (often 15 to 30 minutes). Later builds are faster because of caching.

## If the build fails

Copy the red error lines from the Actions log and ask for help with them.
